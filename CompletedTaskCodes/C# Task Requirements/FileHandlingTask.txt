C# File Handling Task – Static File Class
Task: Employee File Management System

Create a C# Console Application to manage employee information using File Handling.

Use the static File class from System.IO and perform the following file operations.

Employee Details

Each employee should contain:

Employee ID

Employee Name

Department

Salary

Requirements

Create a file named:

employees.txt

Perform the following operations using static File methods:

1. Create / Write File

Use File.WriteAllText() or File.WriteAllLines() to create the file and store at least 5 employee records.

Example:

101,Arun,IT,35000
102,Divya,HR,30000
103,Kumar,Finance,40000
104,Priya,IT,45000
105,Ravi,Sales,28000

2. Read File

Use File.ReadAllText() or File.ReadAllLines() to read and display all employee records.

3. Append Data

Use File.AppendAllText() or File.AppendAllLines() to add 2 new employees without deleting the existing records.

4. Search Employee

Ask the user to enter an Employee ID and search for that employee from the file.

Display:

Employee Found
ID: 103
Name: Kumar
Department: Finance
Salary: 40000

If the employee does not exist:

Employee Not Found

5. Update Employee

Ask the user for an Employee ID and update the employee's:

Department

Salary

Read the existing file, modify the required record, and rewrite the file using a static File method.

6. Delete Employee

Ask the user for an Employee ID and remove that employee from the file.

After deletion, rewrite the remaining records into the file.

7. Check File Information

Use static File methods such as:

File.Exists()
File.GetCreationTime()
File.GetLastWriteTime()
File.GetAttributes()

Display the file information.

8. Delete the File

Add an option to delete the file using:

File.Delete()

Before deleting, check whether the file exists.

Expected Menu

===== Employee File Management =====

1. Create/Write Employees
2. Display Employees
3. Add Employee
4. Search Employee
5. Update Employee
6. Delete Employee
7. File Information
8. Delete File
9. Exit

Enter your choice:

Conditions

Use System.IO.

Use the static File class methods.

Do not use StreamReader or StreamWriter.

Store employee records in employees.txt.

Handle the situation when the file does not exist.

Validate Employee ID before performing update/delete/search.

Use a loop to keep the menu running until the user selects Exit.
