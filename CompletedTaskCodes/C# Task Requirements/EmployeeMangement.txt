Task 2: Employee Management Using List<T>
Objective

Create a console-based Employee Management System using a custom Employee class and List<Employee>.

Employee Class

Create an Employee class with:

EmployeeId
EmployeeName
Age
Salary
Department
Role

Create a List<Employee> and add at least 8 employee objects.
